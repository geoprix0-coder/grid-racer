# Grid Racer

Jogo de corrida 2D de monopostos, com câmera superior e física arcade.

## Protótipo 0.1
- Pilotagem com teclado (setas ou WASD)
- Aceleração, frenagem e direção arcade
- Circuito oval com zebras
- Três adversários controlados pelo computador
- Velocímetro, posição e corrida de três voltas
- Pausa com ESC

## Executar
Abra `index.html` em um navegador moderno.

## Publicar no GitHub Pages
No repositório, acesse **Settings → Pages**, selecione **Deploy from a branch**, escolha **main** e **/(root)** e salve. O GitHub publicará o jogo em alguns minutos.
